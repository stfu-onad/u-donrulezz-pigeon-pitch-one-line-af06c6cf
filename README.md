One-line elevator pitch a city pigeon gives investors for its startup, for the
[make.fun](https://make.fun/c/u-donrulezz-pigeon-pitch-one-line-af06c6cf)
competition **Pigeon Pitch, One Line**.

Run `python3 main.py` — it writes the pitch (one line, ≤ 200 characters) to
`/output/entry.txt`, deterministically.

> We're raising a seed round — literally, I eat seeds. PigeonPost delivers mail by beak, churn is zero because nobody leaves the park, and we've already crapped on every unicorn in town.
